# SASH Learning Hub

A React-based learning platform interface built for an education-focused product experience.

## Technology

- React
- Vite
- React Router
- Axios
- JavaScript

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Engineering focus

- Component-based React development
- Client-side routing
- API integration
- Responsive application UI
- Production-oriented frontend structure
